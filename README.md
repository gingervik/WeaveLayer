# WeaveLayer Mainnet program

Working model for a 12-week Mainnet launch plan (Arkiv TPM assignment). WeaveLayer is a fictional company from the assignment brief.

- **Program board and roadmap:** [GitHub Project "Mainnet launch"](https://github.com/users/gingervik/projects/3), with views by workstream, by gate and a roadmap, plus weekly status updates.
- **Contingency map:** [gingervik.github.io/WeaveLayer](https://gingervik.github.io/WeaveLayer/): 22 "what if" scenarios with signal, first moves, owner, gate and options for leadership.
- **Issues:** one per piece of work, with owner, workstream, gate, week and basis (data pack or assumption), linked by dependencies.

Weeks 1 to 6 on the board are a simulation, marked `[Simulation]` in issue comments, to show how the weekly status looks after the audit report.
